## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | 图标间隙、内联边距、徽章内边距 (`p-1`, `gap-1`, `px-2 py-0.5`) |
| sm | 8px | 紧凑元素间距、徽章外边距 (`p-2`, `gap-2`, `m-2`) |
| md | 16px | 默认元素间距、卡片内边距、按钮外边距 (`p-4`, `gap-4`) |
| lg | 24px | 区域内边距、面板内边距、布局间距 (`p-6`, `gap-6`) |
| xl | 32px | 布局间隙、容器间隙、外层边距 (`p-8`, `gap-8`) |
| 2xl | 48px | 主要区块间隔、垂直布局间隔 (`p-12`) |
| 3xl | 64px | 页面级大间隙 (`p-16`) |

Exceptions:
1. 高度定义：倒计时线性进度条高度固定为 `3px`。
2. 按钮变换动效：Hover 态 `scale-[1.02]` 微动，Active 态 `scale-[0.98]`，锁定淡出态 `scale-95 opacity-0` |
3. 转场延迟：200ms 的平滑淡出转场延迟（`duration-200`），为底层双实例物理切换留出缓冲。

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#020617` (Slate 950) | 网页整体背景、底层视频展示背景及全屏遮罩底层。 |
| Secondary (30%) | `#0f172a` (Slate 900) | 卡片面板容器背景（使用 60% 不透明度 `bg-slate-900/60`）和调试控制面板背景。 |
| Accent (10%) | `#8b5cf6` (Violet 500), `#d946ef` (Fuchsia 500), `#ec4899` (Pink 500) | 交互抉择点、渐变进度条、按钮悬停边框及选中状态高亮。 |
| Destructive | `#ef4444` (Red 500) | 错误状态文字或图标提示。 |

Accent reserved for:
1. `DECISION POINT`（抉择点）微型徽章背景与边框 (`from-violet-500 to-fuchsia-500` 渐变)；
2. 倒计时线性进度条前景 (`from-violet-500 via-fuchsia-500 to-pink-500` 渐变)；
3. 用户选中后的选项按钮背景与边框 (`from-violet-600 to-fuchsia-600` 渐变且边框高亮为 `border-violet-400`)；
4. 未选中选项 hover 时，卡片边框高亮 (`hover:border-violet-500/40`)，以及选项右侧向右滑出的箭头。

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | `选择分支 →` (未选中选项指示) / `已选定 ✓` (已选中选项确认) |
| Empty state heading | `等待交互触发...` |
| Empty state body | `系统正在静默播放视频，到达特定剧情节点时将在此显示抉择卡片。` |
| Error state | `加载分支失败。请刷新页面或重试。` |
| Destructive confirmation | `重置剧情: 确定要重新开始剧情吗？这将会丢失您当前的所有进度。` |
| Destructive Action Confirm | `确认重新开始` |
| Destructive Action Cancel | `继续当前剧情` |
| Badge Content | `DECISION POINT` (决策点指示) |
| Selected Loading | `⚡ Loading Branch...` (正在加载选定分支) |
| Heading Content | `前方的道路发生了分叉，请做出您的抉择：` |
| Timeout Transition | `由于未做出选择，系统已自动流转。` |
