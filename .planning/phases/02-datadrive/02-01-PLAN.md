# Plan: 02-01 (数据驱动逻辑层设计)

## Goal

编写 `storyConfig.json` 的 JSON 格式定义，为引擎的互动拓扑关系结构制定规范契约；用纯 TypeScript 实现核心状态机类 `NodeStateManager`，实现配置文件的静态安全性分析、状态转换路由、多路径分支预加载候选计算，并通过简易验证逻辑确保纯状态机在逻辑上 100% 正确运行。

## Must Haves

- [ ] 在 `public/storyConfig.json` 处定义演示用的互动拓扑数据，包括主视频、交互点、选项和分支 A/B 的映射。
- [ ] 在 `src/engine/types.ts` 定义高类型安全性的接口（`VideoNode`、`VideoInteraction`、`StoryConfig` 等）。
- [ ] 在 `src/engine/NodeStateManager.ts` 实现状态机类，包含状态初始化、订阅模式（注册/分发事件回调）和防错校验（检测配置有无死循环或非法悬空分支节点）。
- [ ] 实现 `getPreloadCandidateNodeIds()` 方法，以便为底层的物理播放器返回当前节点的所有后续流转候选 ID。
- [ ] 编写一个独立的测试或运行脚本，一键运行并验证状态机转移及订阅事件逻辑是否运转正常。
- [ ] `npm run build` 全链路编译无报错。
