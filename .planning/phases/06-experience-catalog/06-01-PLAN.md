# Plan: 06-01 (进度条可跳转及智能拦截机制实现)

<objective>

<task type="auto">
  <name>Task 06-01-02: 在播放器中实现跳转拦截与 Tick 唤醒逻辑</name>
  <files>src/components/InteractivePlayer.tsx</files>
  <action>
    1. 修改 src/components/InteractivePlayer.tsx，为进度条容器绑定 `onClick` 事件（例如 `handleProgressBarClick`）。
    2. 在点击处理函数中，通过 `e.stopPropagation()` 阻止事件向上冒泡到视频播放/暂停拦截器。
    3. 获取进度条容器的 `getBoundingClientRect()`：
       - 计算点击坐标比例：`const rect = container.getBoundingClientRect();`
       - 计算目标比例：`const clickPct = (e.clientX - rect.left) / rect.width;`
       - 获取当前活跃视频的 duration，计算目标时间 `let targetTime = clickPct * duration;`
    4. 拦截算法核心：
       - 获取当前播放节点 `const node = stateManager.getCurrentNode();`
       - 获取当前视频的播放时间 `const currentTime = foregroundVideo.currentTime;`
       - 检查是否存在一个交互点 `interaction.timestamp`：
         - 若 `currentTime < interaction.timestamp` 并且 `targetTime > interaction.timestamp`（即这次跳转跨越了交互点）：
           - 强制把 `targetTime` 重置为 `interaction.timestamp`。
           - 暂停前台播放器。
           - 调用 `stateManager.tick(interaction.timestamp)`，确保瞬间触发 `interactionTriggered` 事件。
       - 设置 `foregroundVideo.currentTime = targetTime`，完成物理跳跃。
  </action>
  <verify>
    - 在运行状态下，点击进度条中后段，检查是否能在跨越交互点时完美停住且立刻弹出交互框。
  </verify>
  <done>跳转拦截核心算法已编写完成，能自动将跳跃目标截断回退至关键分支阈值并激活 UI。</done>
</task>
