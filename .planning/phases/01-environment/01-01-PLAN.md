# Plan: 01-01 (环境与基础设施搭建)

## Goal

搭建 Vite + React 18 + TS + Tailwind CSS 开发环境，并集成 `shaka-player` 与 `@interactive-video-labs/react` 核心交互包装库，在主页实现一个基础的播放与互动依赖验证。

## Must Haves

- [ ] 项目使用 Vite (react-ts 模板) 初始化，确保支持 TypeScript。
- [ ] 成功配置 Tailwind CSS，能够运用 `backdrop-blur-md` 磨砂玻璃等高级类名。
- [ ] 安装并引入 `shaka-player`，在主页上能够渲染一个最简的 `<video>`，并用 Shaka Player 进行实例化。
- [ ] 安装并成功引入 `@interactive-video-labs/react` 核心库，确保顶层路由能正常加载。
- [ ] 配置好开发和打包脚本，确保 `npm run build` 打包完全无误。

## Tasks

### 1. 工程搭建与依赖安装
- [ ] 初始化 Vite 项目 (react-ts 预设)，清理多余的模板代码。
  - **Files**: `package.json`, `index.html`, `src/App.tsx`, `src/main.tsx`
- [ ] 安装开发与核心依赖，包含 `shaka-player`、`@interactive-video-labs/react`、`tailwindcss`、`postcss`、`autoprefixer`。
  - **Files**: `package.json`

### 2. 样式系统集成 (Tailwind CSS)
- [ ] 配置 `tailwind.config.js` 和 `postcss.config.js`，使 Tailwind 能够扫描到 `src` 下 of ts/tsx 文件。
  - **Files**: `tailwind.config.js` [NEW], `postcss.config.js` [NEW]
- [ ] 在全局 CSS 文件中导入 Tailwind CSS 指令，并配置好基础字体（如 `Inter` / `Outfit` 现代字体）与重置样式。
  - **Files**: `src/index.css`

### 3. Shaka Player & Wrapper 与环境冒烟组件实现
- [ ] 在 `App.tsx` 中编写一个高颜值的测试主页：包含一个高质感的毛玻璃容器，内部挂载 Video 元素，使用 React 的 `useEffect` 和 `useRef` 完成 Shaka Player 实例的绑定，并尝试导入并在页面上使用 `@interactive-video-labs/react` 核心包装组件进行环境冒烟。
  - **Files**: `src/App.tsx`
- [ ] 针对 `shaka-player` 的全局 TS 声明进行配置，解决类型系统无法识别 Shaka 全局变量的问题。
  - **Files**: `src/shaka.d.ts` [NEW]

### 4. 验证与构建
- [ ] 运行本地服务验证渲染，确保样式和控制台均正常。
- [ ] 运行打包测试 `npm run build`，确保完美编译通过。

## Verification Plan

### Automated
- `npm run build` — 编译并打包出静态产物，无任何编译报错。

### Manual
- 开启本地 dev 模式 (`npm run dev`)，使用浏览器访问。
- 确认屏幕上渲染出了一张毛玻璃玻璃质感的卡片（证明 Tailwind 生效）。
